# Build Instructions

## Prerequisites

- A working TeX distribution providing `pdflatex`, `biber`, and
  (recommended) `latexmk` — e.g. TeX Live 2022+ or MacTeX. The manuscript
  uses `biblatex` with the `biber` backend (not `bibtex`); `biber` must be
  on `PATH` and its version must match the `biblatex` version pulled in by
  your TeX distribution, or citation processing will fail with a version
  mismatch error.
- Python 3 (any recent 3.x) with no third-party packages required, for
  `scripts/verify_manuscript.py`. (`scripts/make_conceptual_diagram_check.py`
  is only invoked by `make figures`, which is not needed for a normal
  build — see below.)

## Standard build

From the repository root:

```
make pdf
```

This runs `latexmk -r latexmkrc`, which drives the correct
pdflatex → biber → pdflatex → pdflatex sequence automatically and only
re-runs passes that are actually needed, then copies the result to
`build/manuscript.pdf` and `./manuscript.pdf`. A clean build from an
empty `build/` directory takes under a minute on a typical machine.

If `latexmk` is not installed, `make pdf` automatically falls back to a
manual four-pass sequence (see the `Makefile`):

```
pdflatex -interaction=nonstopmode -output-directory=build manuscript.tex
biber --input-directory=build --output-directory=build manuscript
pdflatex -interaction=nonstopmode -output-directory=build manuscript.tex
pdflatex -interaction=nonstopmode -output-directory=build manuscript.tex
cp build/manuscript.pdf ./manuscript.pdf
```

## Verification

```
make verify
```

runs `make pdf` and then `scripts/verify_manuscript.py`, which checks:
compiled PDF exists; no undefined LaTeX cross-references; no undefined
citations; every `\includegraphics` path resolves to a local file; every
citation key used in the manuscript resolves in `references.bib`; every
`references.bib` entry is cited at least once; and the evidence ledger
(`dev_mem/evidence_ledger.md`) covers every orientation value named in
the original task brief. All seven checks must print `[ok]`, ending in
`=== VERIFY PASSED ===`.

## Regenerating figures (not needed for a normal build)

`make figures` only rebuilds the one originally-authored figure
(`figures/main/conceptual_framework.{pdf,png}`, a TikZ diagram built from
`scripts/conceptual_framework.tex`). Every other figure in `figures/` is
a byte-for-byte copy from the source model repository's own output
directories (see `dev_mem/figure_manifest.md` for full provenance) and
is not regenerated by this Makefile — there is no simulation code in
this repository, and `make figures` will not run or invoke the ABM.

## Clean

```
make clean
```

removes `build/`, the root-level `manuscript.pdf`, and the conceptual
diagram's auxiliary build files.

## Expected result (as of this revision)

- `build/manuscript.pdf`: 93 pages, 0 LaTeX warnings, 0 errors (only
  benign `Underfull \hbox` messages from long monospaced identifiers in
  narrow table columns, present since the Level 1.2/1.2b baseline and not
  a regression).
- `make verify` prints `=== VERIFY PASSED ===`.

## Version control

The repository is under git, with the pre-Level-1.3b-revision state
tagged `pre-level13b-revision` (commit `318ec4a`). `git diff
pre-level13b-revision..HEAD` recovers the complete diff of this
revision; `dev_mem/revision_level13b_change_log.md` is the human-readable
summary of the same diff.
