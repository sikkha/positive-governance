# Figure Manifest

All figures below were generated by the source repository's own
`experiments/make_level12_visualizations.py` / `make_level12b_visualizations.py`
scripts and are copied byte-for-byte (never re-rendered, never re-labeled)
from `outputs/level12_figures/` and `outputs/level12b_figures/` in the
source model repository into this paper repository's `figures/main/` and
`figures/appendix/`. One figure (the conceptual-framework diagram) is newly
authored for this paper and is the only figure not sourced from the model
repository.

**Disclosed organizational deviation.** The task brief's own figure plan
recommended organizing figures into `figures/level12b/`, `figures/level13b/`,
and `figures/conceptual/`. This revision creates `figures/level13b/` for
new main-text Level 1.3/1.3b figures but leaves the pre-existing
`figures/main/` and `figures/appendix/` directories (already, in effect, a
complete Level 1.2/1.2b figure set) unrenamed, and places new Level 1.3/1.3b
appendix-placed figures into the existing `figures/appendix/` directory
rather than a separate `figures/level13b/appendix/`. This was a deliberate
choice to avoid a disruptive rename of every one of the 27 pre-existing
`\includegraphics` references across five already-correct section files,
which carried real risk of introducing a build-breaking path error for no
scientific benefit; the underlying organizational intent (new material
separated from old, both clearly traceable) is preserved. No new conceptual
figure was authored this revision; the figure plan's instruction to reuse
existing figures only was followed throughout.
