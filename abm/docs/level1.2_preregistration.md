# Level 1.2 Preregistration — Stage 0

This document is the human-readable companion to the frozen, hashed
Stage 0 manifest generated by `experiments/level12_preregistration.py`
and stored at `outputs/level12_stage0_preregistration/manifest.json`
(hash in the sibling `manifest_hash.txt`). Every commitment below was
fixed and frozen BEFORE any Stage 1-7 run — `load_and_verify_manifest()`
is called at the start of every subsequent stage script and raises
`ValueError` if the on-disk manifest's content no longer matches its
recorded hash, making Section 20's "never alter the model or rerun
searches merely because the outcome differs from the dissertation"
stop condition mechanically checkable, not just a stated intention.

## What is frozen

- **Mechanism-activation flags** (`MECHANISM_ACTIVATION_FLAGS`): the
  five Work Package B/C/D/F config flags every stage script must
  report the on/off state of.
- **Stage sample sizes** (`STAGE_SAMPLE_SIZES`): disclosed, session-
  compute-budget-scaled seed/population/step counts for all seven
  stages, fixed before any stage ran.
- **Discovery pipeline commitments**: imported directly from
  `observer/phenotype_discovery.py`'s own `CANDIDATE_METHODS`,
  `DEFAULT_K_RANGE`, `MISSINGNESS_STRATEGIES` constants — never
  restated by hand, so the manifest cannot silently drift from the
  code it freezes.
- **Recurrence/convergence commitments**: imported from
  `observer/recurrence_criteria.py`'s `RECURRENCE_CRITERIA_NAMES` and
  `observer/convergence_tests.py`'s `CONVERGENCE_CLASSIFICATION_LABELS`
  — a straight conjunction rule (all 12 criteria must pass), never a
  majority vote.
- **RNG discipline**: `rng_mode="mechanism_substreams"` mandatory for
  every Level 1.2 causal run this milestone.

## Verification

```
python3 -c "from experiments.level12_preregistration import load_and_verify_manifest; print(load_and_verify_manifest())"
```

recomputes the SHA-256 over the on-disk manifest's canonical JSON and
compares it against the stored hash file, raising on any mismatch.
`tests/test_level12_preregistration.py` (11 tests) covers determinism,
all-seven-stage coverage, source-constant fidelity, hash stability
under key reordering, round-trip write/verify, and explicit tamper
detection.

## Where sample-size commitments were interpreted (disclosed)

Two of the frozen numbers (`n_seeds`, `n_parameter_draws`) admit more
than one literal reading when a stage combines both; each stage script
states, in its own docstring, exactly how it interpreted them, before
running:

- Stage 3: `n_seeds=24`, `n_parameter_draws=12` → 12 draws × 2 seeds
  each = 24 total runs (not 12×24=288).
- Stage 5: `n_seeds=12` → 12 draws (reusing Stage 3's own fixed-seed
  Latin Hypercube) × 1 fresh seed each = 12 total.
- Stage 6: `n_seeds=6` across 4 scale conditions → interpreted as 2
  seeds/condition = 8 total (the literal 6/4 split is not evenly
  divisible; recorded as a disclosed deviation).
- Stage 7: `n_seeds=6`, `n_perturbation_types=2` → 3 seeds/type = 6
  total shocked/unshocked pairs (divides evenly; taken literally).

None of these interpretations were revisited after seeing any stage's
results.
