# Level 1.3 Preregistration — Section 15

This document is the human-readable companion to the frozen, hashed
manifest generated by `experiments/level13_preregistration.py` and
stored at `outputs/level13_preregistration/manifest.json` (hash in the
sibling `manifest_hash.txt`:
`f0e92598ec063997b8674b0a000f618f1009b1c1e28c707ccad31332512c749b`).
Every commitment below was fixed and frozen **before** any Stage 0-9
run executed — `load_and_verify_manifest()` raises `ValueError` if the
on-disk manifest's content no longer matches its recorded hash.

## What is frozen, and where each field's value actually comes from

**Assembly, not invention.** Exactly like `experiments/level12_
preregistration.py`'s own precedent, the manifest imports every field
LIVE from the module that already owns it, so it can never silently
drift from the code it describes:

- **Mechanism activation flags** (`MECHANISM_ACTIVATION_FLAGS`) — the
  seven config flags (`historical_module_enabled` plus the three
  Work-Package-A master flags, `entrenchment_enabled`, and the two
  Work-Package-D legitimacy flags) any Stage 0-9 script must report
  the on/off state of, restated directly here rather than imported
  from a `tests/` private tuple (an experiment script importing from
  `tests/` would be backwards — this manifest is what a test
  cross-checks, not the reverse).
- **Discovery-pipeline commitments** — `CLUSTERING_PIPELINE_VERSION`,
  `CANDIDATE_METHODS`, `DEFAULT_K_RANGE`, `MISSINGNESS_STRATEGIES`
  from `observer/phenotype_discovery.py` (Level 1.2's own module,
  reused unmodified); `LEVEL13_DIMENSION_KEYS` from `observer/
  level13_phenotype.py`.
- **Sequencing commitments** — `INSTITUTIONAL_RESPONSE_DIMENSIONS`
  from `observer/sequencing_diagnostics.py`.
- **S_obs/Z_obs commitments** — the exact response-dimension
  membership of both composites, imported from `observer/sz_obs.py`.
- **Counterfactual commitments** (Work Package E) — the two named
  transforms and the `historical_pressure_series_override` mechanism,
  from `core/historical_counterfactuals.py`.
- **Conversion commitments** (Work Package F) — `FUNCTION_FAMILIES`
  from `observer/institutional_conversion.py`, plus the default
  window/persistence thresholds.
- **Ecological feasibility commitments** — the parameter-space field
  names and LHS seed from `experiments/level13_common.py`; the actual
  cut points are frozen separately at Stage 2, not here — this
  manifest commits only to the machinery and parameter space, before
  any draw is scored.
- **RNG commitments** — `rng_mode="mechanism_substreams"` and
  `RNG_REGISTRY_VERSION` from `core/rng.py`, restated here as a
  blanket, mandatory-for-every-stage commitment. (Task #109 found and
  fixed three stage scripts that silently violated this before it was
  ever checked mechanically — see `docs/level1.3_bug_disclosure_and_
  reproducibility_note.md` and the standing regression guard,
  `tests/test_level13_rng_mode_compliance.py`.)

**One field had no existing home and was frozen here for the first
time, before Section 23 could be reached:**

- **`DECISION_GATE_OUTCOMES`** — the six-way outcome space (one
  family, two families, four-or-more families, a continuum, transient
  differentiation, or no detectable effect) plus `DECISION_GATE_DO_
  NOT_PREFER = "E_transient_differentiation"` and its own scoping
  note. This is a direct, disclosed transcription of `docs/level1.3_
  theoretical_translation.md` §6's own recovered prose (written while
  the source spec text was still in context, before this session's
  compaction), not a reconstruction from memory — preregistered here,
  before any Stage 0-9 run, precisely so it cannot be quietly reworded
  later to fit whatever a run turns up. `DECISION_GATE_NOTE` makes
  explicit that "do not prefer E" governs the discovery pipeline's own
  default, not the data: no Stage 6-9 script may special-case or bias
  toward classifying a result as transient differentiation over the
  other five options.

## Disclosed sample sizes (`STAGE_SAMPLE_SIZES`), fixed before any stage ran

| Stage | Committed scale |
|---|---|
| 0 exact compatibility | 20 matched seeds x 2 comparisons |
| 1 mechanism activation | 8 seeds x 7 conditions |
| 2 ecological calibration | 30-point LHS |
| 3 sequencing x entrenchment factorial | 6 seeds x 6 orderings x 2 (entrenchment on/off) = 72 runs |
| 4 open pressure-history search | 24 LHS points x 4 seeds = 96 runs |
| 5 causal counterfactuals | 16 matched seed-triples = 48 runs |
| 6 blind phenotype discovery | no new runs — pools Stage 3+4+5 |
| 7 fresh confirmation | 12 fresh, never-reused seeds |
| 8 S_obs/Z_obs mapping | no new runs — reuses Stage 3+4+5+7's own event logs |
| 9 scale and shock robustness | 6 seeds x 2 populations x 2 patch counts = 24 runs |

Every commitment above was scaled to this session's compute budget,
not to any publication target, and stated before any run so it could
not be quietly adjusted afterward — same disclosed-scaling discipline
`docs/level1.2_preregistration.md` and `docs/level1.2b_preregistration.
md` both state for their own milestones.

## Explicit run-count arithmetic, achieved vs. committed

- Stage 0: committed 20x2=40 comparisons. **Achieved: 20/20 seeds,
  both comparisons, `overall_pass=True`.**
- Stage 1: committed 8x7=56 runs. **Achieved: 8 seeds x 7 conditions,
  all checks pass.**
- Stage 3: committed 72 runs. **Achieved: 72/72**, after being re-run
  once under the corrected substrate/transmission-flag fix (task #109;
  the pre-fix 72/72 run is archived, not counted as the achieved
  figure).
- Stage 4: committed 96 runs. **Achieved: 96/96**, likewise re-run
  once under the same fix.
- Stage 5: committed 16 matched triples (48 runs). **Achieved:
  16/16 — this stage never ran under the pre-fix substrate at
  experimental scale, only at single-seed diagnostic scale (see the
  bug-disclosure note).**
- Stage 7: committed 12 fresh seeds. **Achieved: 12/12.**
- Stage 9: committed 24 runs. **Achieved: 24/24, all manipulation
  checks passed.**

No stage in this milestone reduced its committed sample size below the
number frozen in `STAGE_SAMPLE_SIZES`. The one disclosed non-default
choice made after preregistration — Stage 9's `N_SHOCKS=4` (distinct
from `PressureHistorySpec`'s own class default of 3, chosen explicitly
to avoid even the appearance of privileging the number three as a
governance-family count) — is a run-shape detail the manifest left
unspecified, not a violation of any frozen number; it is disclosed in
Stage 9's own script docstring and repeated in `docs/level1.3_
scientific_note.md` §10.

## Verification

```
python3 -c "from experiments.level13_preregistration import load_and_verify_manifest; print(load_and_verify_manifest())"
```

recomputes the SHA-256 over the on-disk manifest's canonical JSON and
compares it against the stored hash file, raising `ValueError` on any
mismatch. `tests/test_level13_preregistration.py` covers completeness,
values-imported-not-hand-copied, decision-gate-outcome content
(including the "do not prefer E" provenance and scoping note), RNG
commitments, hashing (determinism, JSON-serializability, save/load/
verify roundtrip, tamper detection), and verification of the actual
saved manifest against its own hash.

## Context-loss disclosure, restated

As `experiments/level13_preregistration.py`'s own module docstring
states directly: most of this milestone's work needed to disclose
interpretive judgment calls because the verbatim spec text for later
sections was lost to compaction. Section 23's six-way decision gate is
the one field in this manifest for which the exact source-spec wording
was independently recovered and confirmed elsewhere in this session's
own record before being transcribed here — every other field in this
manifest is either imported live from already-built, already-tested
code (so it cannot drift from spec-as-implemented) or a disclosed,
session-budget-scaled sample-size decision, never a reconstruction of
lost spec prose presented as verbatim.
